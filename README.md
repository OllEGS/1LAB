# ЛР № 1 по теории многоагентных систем

Распределённая курьерская доставка. Рыбочкин Олег, Б24-507.

## Запуск

Распакуйте архив и откройте терминал в папке с main.py. Нужен Python 3.10 или новее. Сторонних зависимостей нет.

```powershell
py main.py all
py main.py fail-hub
```

В Linux или WSL используйте `python3 main.py all`.

| Режим | Что показать |
|---|---|
| normal | Назначение K1, выдача со склада W, доставка за 9 минут |
| fail-before | Отказ до выдачи. K2 забирает заказ со склада по новой версии назначения |
| fail-hub | Подтверждённая сдача груза в H и назначение K2 от узла H |
| lost-contact | Груз у недоступного курьера. Заказ переходит в RECOVERY |
| road-closed | Курьер пересчитывает остаток маршрута при закрытии H–D |

Файл demo.txt содержит фактическую консольную трассу всех режимов. Строки со стрелкой между агентами и кодом сообщения учитываются в метрике. Строки перемещения и тайм-аут не считаются сообщениями.

Модель использует один процесс и модельное время. Средства связи, роли и правила заданы явно. Подтверждения передаются мгновенно, тайм-аут/обработка отказа занимает 2 модельные минуты. В учебной карте используются наземные маршруты. Для роли дрона проектом предусмотрен отдельный граф воздушных коридоров.
